# Research

Dated research notes, gathered automatically each weekday morning.

**These files are machine-generated.** They collect public information — pricing pages, changelogs, filings, funding announcements, review-site themes, recent news — into one place so the writing sessions can start from facts instead of from a search box.

Every file carries a header saying what generated it and when. Nothing here is analysis, and nothing here should be quoted as if it were.

The analysis lives in [`teardowns/`](../teardowns/), and it's written by hand.

## Naming

`YYYY-MM-DD-<product>.md`
