## Two documented front doors

Stripe runs a developer path and a merchant path from the same signup. Per a fintech-onboarding review, a developer gets API keys and a working sandbox "within seconds of entering an email, with no business verification needed to start building," while merchant activation is a separate gated flow with a progress bar, inline validation, and three integration modes (hosted, embedded, API) — [themasterly.com](https://www.themasterly.com/blog/fintech-onboarding-ux) (no publication date shown). The same source says returning founders can transfer verified business details to a new account instantly; first-time users have no equivalent shortcut.

The docs are part of the developer path: three-column layout with per-product quickstarts, hover-to-highlight between prose and code, and a field where you paste a **test** key and run live calls from the page — [Moesif DX teardown](https://www.moesif.com/blog/best-practices/api-product-management/the-stripe-developer-experience-and-docs-teardown/) (page dated May 22, 2026; vendor-published, treat claims accordingly).
