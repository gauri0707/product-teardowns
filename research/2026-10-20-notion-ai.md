## Entry points, per Notion's own docs

From [Everything you can do with Notion AI](https://www.notion.com/help/guides/everything-you-can-do-with-notion-ai) and [Get started with Notion Agent](https://www.notion.com/help/notion-agent), both accessed 2026-10-20.

- **Floating face icon**, bottom-right of any page — described as the "friendly face at the bottom of Notion." Opens chat beside the page.
- **"Search" in the left sidebar** — expands into a full-page AI view.
- **Desktop shortcut** `Shift+Cmd+J` / `Shift+Ctrl+J` — works outside Notion, desktop app only.
- **Inbox** — agent icon at the top of the inbox panel.
- **Selected blocks** — selecting blocks scopes the agent to them.
- **Context controls inside chat:** `@` to add a page or person, `All sources` picker (Slack, Drive, a specific hub), `📎` file attach, `Auto` or a manually chosen model.
- **Database builder:** new page → `Database` → `Build with AI`.
- **Chat history** is behind a hover state (sidebar → hover `Notion AI` → 🕘) *or* the three-dot menu → "View History" — the two help pages describe it differently.

Notably **not documented as entry points** in the main AI guide: an inline editor affordance, a slash command, meeting notes, or autofill. The guide describes no guided first-run flow; shortcuts, the source picker, `@` mentions and the database builder appear only inside tips, callouts and "click to expand" sections.

## The gate a new user hits

[Complimentary AI responses](https://www.notion.com/help/complimentary-ai-responses) (accessed 2026-10-20): "Everyone can try Notion AI for free." The **exact allowance is not published** — no number of responses is stated anywhere on the page. What counts as a response: any AI action that returns a response, including AI blocks, autofill properties, and questions; **"Try again" counts as an additional response.** On exhaustion the user sees a message that Business or Enterprise is needed to continue. Two hard constraints on who can clear the gate: **only a workspace owner can upgrade, and the upgrade must be done on desktop.**

## Custom Agent setup — the long flow

[Custom Agents in Notion](https://www.notion.com/help/custom-agents), accessed 2026-10-20. Business/Enterprise only; **building or editing requires desktop or web** (not mobile). Six stages: `Agents` sidebar → `+`, choosing *Create with AI chat*, *Create from a template*, or *Create from scratch* → write `Instructions` → set `Triggers` (Recurring, Notion events, or Slack; combinable, filterable) → configure `Tools and access` → choose `Model` → save, publish, and `Share` at "Full Access," "Can Edit," or "Can View and Interact."

Documented traps in that flow, in Notion's own words: **linking to a page in `Instructions` does not grant access** — it must be added under `Tools and access`; agents have no full workspace access by default; **embedding an agent in a page does not grant access to it**; duplicating an agent drops tool connections, Workers and run history and starts private; Slack triggers need a Slack admin to connect first and need the workspace to allow member-created user groups.

Documented capability gaps for the main agent ([notion.com/help/notion-agent](https://www.notion.com/help/notion-agent)): cannot create database automations, templates, page layouts, rollups or buttons; cannot create or edit comments, share pages, change permissions, start AI Meeting Notes, or change workspace settings; cannot read non-PDF embeds such as video transcripts. That page **contradicts itself** on formulas — listed both as a capability and as something it can't create.
