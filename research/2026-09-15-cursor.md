## The journey Cursor documents

**Quickstart, five named steps** ([cursor.com/docs/get-started/quickstart](https://cursor.com/docs/get-started/quickstart), accessed 2026-09-15): 1. *"Install Cursor and sign in"* (download, authenticate, open a folder, start with a small task) · 2. *"Ask Cursor to explain your codebase"* (Agent via ⌘I / Ctrl+I) · 3. *"Make one small change"* · 4. *"Review the diff and verify the result"* · 5. *"Use Plan Mode for bigger changes"* (Shift+Tab). The first action after sign-in is not writing code — it is asking Agent to explain the repo.

**First project** ([cursor.com/help/getting-started/first-project](https://cursor.com/help/getting-started/first-project), accessed 2026-09-15): File > Open Folder → ⌘I → an example prompt, *"Add a dark mode toggle to the settings page."* Agent *"will explore your codebase, edit files, and show its changes."* Recommends `@` file references (e.g. `@auth.ts`) over automatic search.

**Migration step** ([cursor.com/docs/configuration/migrations/vscode](https://cursor.com/docs/configuration/migrations/vscode), accessed 2026-09-15): Cursor Settings (⌘/Ctrl+Shift+J) → General > Account → Import, which transfers *"Extensions," "Themes," "Settings," "Keybindings."* The page lists nothing that fails to carry over — **no caveats are documented**.
