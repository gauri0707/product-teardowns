## The documented onboarding path

Linear's own start guide sequences a new workspace as: watch the "Intro to Linear" walkthrough → explore the demo workspace → sign up with a work email and create a workspace → pick a setup guide sized to the company (small team / startup / scaling) → onboard teammates. The guide leads with watching and exploring rather than configuring, and it names **no default teams, issue types, cycles or triage settings** — setup is framed as per-organisation. ([Linear Docs, Start Guide](https://linear.app/docs/start-guide), accessed 2026-09-29)

## Screen-by-screen, as published

A third-party teardown counts **6–7 screens**: Google OAuth → workspace creation with domain auto-join → theme selection (light/dark) → a Cmd+K command-menu tutorial → optional GitHub integration → optional teammate invites → a "Get familiar with Linear" checklist. It flags two frictions — the workspace URL is pre-filled with a *generated slug* rather than the actual domain, and an active-issues popup on entry assumes context a new user does not have — and identifies the activation event as **resolving** a first issue, not creating one. ([Supademo, Linear onboarding teardown](https://supademo.com/user-flow-examples/linear), accessed 2026-09-29)

A second teardown counts "10+ steps" across two phases (must-do setup incl. email verification, then split beginner/advanced paths), praises the hands-on-over-instructional approach, and offers no criticisms. Same article claims Linear runs with a single PM and does not A/B test, deciding on "taste and opinions." ([Lulu Wang, *Design Bootcamp*](https://medium.com/design-bootcamp/hands-on-learning-cinematic-transition-linears-thoughtful-onboarding-aa4f16c33d90), 2025-02-20)

The two sources disagree on step count (6–7 vs 10+); neither dates its walkthrough, and both predate the March 2026 UI refresh below. Treat both as stale.

## What changed in the flow this year

- **UI refresh** — headers, navigation and view controls made consistent across projects, issues, reviews and documents; icons redrawn; sidebars dimmed so the content area dominates. Stated goal: "a calmer, more consistent interface." ([Linear Changelog](https://linear.app/changelog/2026-03-12-ui-refresh), 2026-03-12)
- **Priority inbox** — notifications split into tabs, Linear choosing what lands in Priority by default, user-customisable by source or filter, with an opt-out back to the old inbox. Stated problem: an active workspace generates enough notifications that "a review blocking a release" gets buried. **On by default.** ([Linear Changelog](https://linear.app/changelog/2026-09-03-priority-inbox), 2026-09-03 — 26 days old)
- **Linear Agent** ([2026-03-24](https://linear.app/changelog/2026-03-24-introducing-linear-agent)), **Code Intelligence** ([2026-05-14](https://linear.app/changelog/2026-05-14-code-intelligence)), **Coding sessions in Linear** ([2026-06-11](https://linear.app/changelog/2026-06-11-coding-sessions)) — titles and dates confirmed from the changelog index; contents not fetched today.

## Recurring complaints about the flow

From G2's aggregated pros-and-cons view ([G2, Linear reviews](https://www.g2.com/products/linear/reviews?qs=pros-and-cons), accessed 2026-09-29):

- **Initial confusion** — 4 reviews; "the layout was a bit confusing at the beginning."
- **Jira-migration learning curve** — multiple reviews; "it can take a bit of time to get used to… once you get familiar with the workflow and shortcuts, it becomes much easier."
- **Cross-team navigation** — default navigation "shows only the ticket hierarchy for your team," with "no clear path to browse tickets from other teams"; one 2.5/5 review adds that "the permission settings aren't clearly explained."
- **Back-button state loss** — "hitting back takes me to the top of the list instead of returning me to where I left off" (2 reviews).
- **Hidden affordances** — Kanban board view described as "somewhat hidden away."
- **Opinionated structure** — the product "trades flexibility for speed"; for teams whose workflows don't match Linear's assumptions the structure is "more of a fight than a help."

Exact G2 review count and overall rating: **not found** (the pros-and-cons view did not surface them).

## Three questions today's session should answer

1. Linear's activation event is *resolving* an issue, not creating one — which means the onboarding has to manufacture work that didn't exist before you signed up. Where in the walkthrough does the product cross from teaching you the tool to making you invent a task, and does that seam show?
2. Reviewers say cross-team navigation has "no clear path" while Linear ships a default sidebar scoped to one team. Is that a gap in the flow, or the opinionated bet working as intended — and what would distinguish the two from inside a 25-minute walkthrough?
3. Priority inbox now decides, by default, which notifications you see first. In a product whose pitch is that *you* hold the model of the work, what does handing that triage judgment to the system do to the core loop?
